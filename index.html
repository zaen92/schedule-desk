AI 비서 (Gemini)

Google AI Studio에서 받은 Gemini API 키를 넣으면 비서에게 말로 부탁할 수 있어요. 키는 내 계정 안에만 저장되고, 비서에게 말할 때마다 내 시간표·할 일·회고·가계부 요약이 함께 Google로 전송돼요.

키 받는 곳: aistudio.google.com/apikey

하루 시간

일어나서 잠들기 전까지의 시간이에요. 주간 탭의 '쓸 수 있는 시간'과 시간표 범위에 쓰여요.

데이터 백업

시간표·루틴·할 일·회고·집중 기록·가계부를 파일 하나로 내려받거나, 백업 파일에서 다시 가져와요. 가져오면 같은 항목은 덮어쓰고 나머지는 그대로 둬요.

앱처럼 쓰기

  1. 아이폰 · Safari에서 이 주소를 열고 공유 버튼 → '홈 화면에 추가'
  2. 안드로이드 · Chrome에서 이 주소를 열고 ⋮ 메뉴 → '홈 화면에 추가' 또는 '앱 설치'
  3. 컴퓨터 · Chrome 주소창 오른쪽의 설치 아이콘을 누르면 창으로 따로 열려요
